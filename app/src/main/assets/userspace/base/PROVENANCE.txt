AliasNull base userspace artifact - provenance and scope
(Part 27-R, Part 27-S2, Part 27-T1, Part 27-T2)

Scope of this artifact
----------------------
This artifact is the versioned base-userspace FOUNDATION for AliasNull. It
establishes, in the app-private runtime directory, a real, verified, versioned
record of what the AliasNull base userland is and is not, so that later
milestones can install genuine components on a known-good base. It is not a
shell, not a command backend, not a native runtime, and not a Linux rootfs.

Provenance of every file
------------------------
The documentation/metadata files (VERSION, ARCH, DESCRIPTION, PROVENANCE.txt,
LICENSE.txt) are original AliasNull-authored files produced from the AliasNull
repository and bundled verbatim into the signed APK.

aliasnull_base_probe is the real executable component of the AliasNull base
userspace (Part 27-S2). Its provenance:

  - Component:      aliasnull_base_probe
  - Executable ver: 1
  - Source file:    app/src/main/cpp/aliasnull_base_probe.cpp
  - Source project: AliasNull (this repository)
  - Build system:   CMake + Android NDK android.toolchain.cmake
  - Toolchain NDK:  28.2.13676358 (NDK r28c)
  - Target ABI:     arm64-v8a (AArch64, 64-bit)
  - Android API:    26 (PIE executable, interpreter /system/bin/linker64)
  - Output:         two deterministic modes, selected only by whether the
                    executable is launched under the controlled base-execution
                    environment (Part 27-T1):
                      DEFAULT (no ALIASNULL_BASE_ENV, or a different value):
                        prints "AliasNull base userspace OK\n" and exits 0 -
                        unchanged since Part 27-S2, so the base-executable
                        diagnostic contract is byte-stable;
                      CONTROLLED ENVIRONMENT (ALIASNULL_BASE_ENV exactly equal to
                        the fixed marker "AliasNull controlled base environment",
                        which is exactly the one override the execution
                        environment supplies): prints "AliasNull base environment
                        OK\n", "cwd=<the real working directory>\n" and
                        "ALIASNULL_BASE_ENV=<marker>\n", then exits 0. The
                        controlled working directory and that one override come
                        ONLY from the verified base userspace and the fixed
                        execution-environment policy - never from UI or user
                        input - and the base-environment diagnostic asserts them
                        exactly, so it proves the child really ran under them.
  - Nature:         a normal executable; never a JNI library, never loaded with
                    System.loadLibrary, and never part of libaliasnull_runtime.so
  - License:        AliasNull project source terms (see LICENSE.txt)

aliasnull_digest is the second real executable component of the AliasNull base
userspace and its first genuinely REUSABLE component (Part 27-T2): a
read-only, dependency-free SHA-256 file-digest utility. Its provenance:

  - Component:      aliasnull_digest
  - Executable ver: 1
  - Source file:    app/src/main/cpp/aliasnull_digest.cpp
  - Source project: AliasNull (this repository)
  - Build system:   CMake + Android NDK android.toolchain.cmake
  - Toolchain NDK:  28.2.13676358 (NDK r28c)
  - Target ABI:     arm64-v8a (AArch64, 64-bit)
  - Android API:    26 (PIE executable, interpreter /system/bin/linker64)
  - Output:         a controlled mode selected ONLY by the one AliasNull-owned
                    environment override ALIASNULL_DIGEST_ROOT being exactly the
                    absolute path of the verified installed base-userspace root
                    (the digest's controlled root is never an argv argument, so
                    no argument passes through the linker unverified): the
                    component hashes exactly the installed base files (VERSION,
                    ARCH, DESCRIPTION, PROVENANCE.txt, LICENSE.txt,
                    aliasnull_base_probe, aliasnull_digest - the same files, in
                    the same order, as the base manifest) and prints one
                    "sha256  name" digest line per file, then exits 0. The Base
                    Digest diagnostic asserts that output exactly against the
                    manifest, so a real userspace executable must independently
                    reproduce the bootstrap's manifest digests for the whole
                    installed base. The SHA-256 is a FIPS 180-4 implementation
                    authored in the source, not a cryptographic library; the
                    component links only Bionic libc and never executes a
                    command.
  - Nature:         a normal executable; never a JNI library, never loaded with
                    System.loadLibrary, and never part of libaliasnull_runtime.so
  - License:        AliasNull project source terms (see LICENSE.txt)

The executables shipped in the APK are the exact artifacts produced by the
"Build AliasNull Android" CI workflow from the committed sources above. Their
source revisions, CI run ids and workflows, and their expected SHA-256 digests
are recorded in the base-userspace artifact manifest (app/src/main/java/app/
aliasnull/shell/bootstrap/BaseUserspaceArtifact.kt), which is the single source
of truth for those digests - they are not silently hard-coded. CI fails unless a
fresh rebuild of each committed source reproduces the committed bytes, and the
bootstrap verifies each digest, the 64-bit AArch64 ELF format and the executable
permission before it reports the base userspace installed.

Why each file is required
-------------------------
  VERSION        - single source of truth for the base artifact version so the
                   bootstrap can distinguish an already-installed matching base
                   from a different/upgradeable one without guessing.
  ARCH           - records the supported ABI so a future arm64 tool installer
                   can assert compatibility instead of assuming it.
  DESCRIPTION    - a precise statement of what the artifact is (and is not) so
                   no future reader mistakes it for a real filesystem.
  PROVENANCE.txt - this file: traceable provenance per component, as required
                   for any component shipped in the base artifact.
  LICENSE.txt    - licensing note.
  aliasnull_base_probe - the real 64-bit AArch64 base-userspace executable,
                   exercised through the controlled developer-diagnostic test
                   panel (Base Executable / Base Environment), never through the
                   Shell command surface.
  aliasnull_digest - the real 64-bit AArch64 SHA-256 file-digest component,
                   exercised through the Base Digest diagnostic, never through
                   the Shell command surface.

No Android /system binaries are part of this artifact. The controlled native
runtime tests (Echo/Stderr/Non-zero Exit/Launch Failure/Base Executable/Base
Environment/Base Digest) run strictly internally for diagnostics; those host
probes and the bundled executables are not general Shell commands.

Honest limitation
-----------------
This artifact deliberately contains exactly two executables and no shell, no
general command runner, and no Linux userland. Python, Git, a package manager,
and arbitrary command execution are NOT included; the AliasNull Shell still
answers only its existing vocabulary (help/about/clear/echo) and reports unknown
commands as unknown. Later milestones layer real, separately produced arm64
components on this verified base.
